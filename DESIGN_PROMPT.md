# FreeMusic Visual Direction Prompt

Use this as the design prompt for future UI work:

Create an original dark minimalist iPhone music-player interface closely matching the composition and UX patterns of premium streaming UI kits, but do not copy any brand logo, brand name, or trademarked visual identity.

Keep only the real FreeMusic app surfaces: Home, Library, Search, Playlist details, Mini Player, and Now Playing. Do not invent podcast, concert, or extra settings tabs.

Visual system:
- Deep black background with slightly raised charcoal cards.
- Rounded iPhone-style panels, compact spacing, large album artwork, clean lists.
- White primary text, muted gray metadata, one green accent for active play, selected tabs, progress, and primary buttons.
- Bottom navigation has only Home, Search, and Your Library.
- Home uses a "Good afternoon" header, a two-column quick-access grid, horizontal album/track shelves, and compact playlist cards.
- Search uses a large search field plus colored browse tiles, not an empty instructional page.
- Library uses a compact "Your Library" header with avatar, search, plus action, filter chips, dense media rows, and a green floating/inline play action when useful.
- Playlist detail uses a dense dark header, large artwork, green play button, and track rows.
- Mini player has a three-dot menu for switching visual style:
  - Compact: artwork thumbnail, title, artist, play button, thin progress.
  - Record: small vinyl/record presentation, title, artist/time, play button, thin progress.
- The current record-style full player remains available, but its materials should match the dark card system.

Avoid:
- Spotify/Yandex/Apple logos or copied brand names.
- Extra tabs or features that the app does not actually have.
- Bright gradient-heavy pages.
- Light vinyl-card UI unless explicitly requested.
- Marketing screens instead of usable app screens.
